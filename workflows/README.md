# Workflows

POPs (Procedimentos Operacionais Padrão) em Markdown. Cada arquivo define como executar um processo completo.

## Estrutura de um workflow
```
# Nome do Workflow

## Objetivo
O que este workflow faz e por quê.

## Entradas
O que é necessário para iniciar.

## Passos
1. Passo 1 — qual ferramenta usar e por quê
2. Passo 2 — ...

## Saídas
O que é produzido e onde vai parar.

## Casos extremos e erros comuns
O que pode dar errado e como lidar.
```
