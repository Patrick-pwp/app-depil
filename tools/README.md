# Tools

Scripts Python para execução determinística. Cada script faz uma coisa bem feita.

## Convenções
- Cada script aceita argumentos via linha de comando ou lê de `.tmp/`
- Saída vai para `.tmp/` ou direto para serviços na nuvem
- Erros são logados com mensagens claras
- Sem lógica de negócio aqui — apenas execução
